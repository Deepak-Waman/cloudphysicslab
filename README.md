# Cloud Physics Lab 🌩️

An open-access interactive learning platform for cloud microphysics, 
secondary ice production, and aerosol–cloud–lightning science.

🌐 Live site: https://deepakwaman.github.io/cloudphysicslab

## What is this?

Cloud Physics Lab makes cutting-edge atmospheric science accessible 
to students, educators, and curious minds worldwide. Learn through 
interactive lessons explained by Dr. Nimbus — an animated cloud 
physicist guide.

## Topics Covered

- ❄️ Secondary Ice Production (SIP)
- 💧 Köhler Theory & Cloud Condensation Nuclei
- ⚡ Aerosols & Lightning
- 🌩️ Deep Convective Clouds
- 🔬 Ice Nucleation
- ☁️ Wegener–Bergeron–Findeisen (WBF) Process
